📡 Что такое азбука Морзе

Каждая буква и цифра кодируется последовательностью из двух символов:

  • Точка (·) — короткий сигнал
  • Тире (−) — длинный сигнал

Например, буква А — это:

·−

Буква С (SOS-ный) — это три точки:

···

📱 Управление на телефоне (главное!)

  • 👆 Быстрое касание экрана (в любой части игровой зоны) → точка
  • 👆 Долгое удержание (палец прижат) → тире
  • Есть вибро-отклик — телефон коротко дрогнет при каждом сигнале
  • Кнопки • и — внизу — для явного ввода одним кликом
  • Держите палец сколько угодно — работает как настоящий телеграфный ключ

💡 Порог тире настраивается — по умолчанию 150 мс.

⌨️ Управление клавиатурой

  • Пробел — короткое нажатие = точка, длинное = тире
  • . — быстрый ввод точки
  • - — быстрый ввод тире
  • Backspace — удалить последний символ
  • Enter — подтвердить букву (если автоприём выключен)

🖱️ Управление мышью

  • Кнопка • — ввод точки
  • Кнопка — — ввод тире
  • Кнопка ПРОБЕЛ — удерживайте ЛКМ: коротко = точка, долго = тире

🎮 Режимы игры

  • 🎯 Одиночная игра — буквы по одной, очки за верный набор
  • 📝 Режим слов — собираете слова по буквам (автоприём включён)
  • 📡 Военные сигналы — SOS, MAYDAY, авиация, флот, армия
  • ⚔️ Мультиплеер — два игрока ходят по очереди

💡 Совет

Слушайте ритм, а не считайте точки. Начните с коротких букв: Е (·), Т (−), А (·−), Н (−·). Потом переходите к словам.
